## 증상 재현과 측정
증상을 고치는 작업이 아니라 규칙을 맞추는 작업이라, 차이마다 켜고 끌 수 있는 임시 버전(저장소 밖, `go test -overlay`)으로 효과를 쟀습니다.
- **붓기:** 반지름 4 붓으로 높이 200에서 1600칸을 부었을 때 중앙 높이와 무게중심 x 오프셋
- **덩어리:** 40×40 덩어리가 무너진 뒤의 더미

| 구성 | 붓기 높이 | 무게중심 | 덩어리 더미 |
|---|---|---|---|
| 수정 전 | 67 | +0.91 | 높이 39, 바닥 80 |
| S3만 | 89 | +0.76 | 같음 |
| S5만 | 91 | +0.18 | 같음 |
| 전부 | 79 | **−1.24** | 같음 (무게중심 −1.27) |
| S6만 빼고 전부 | 79 | +0.23 | 같음 |
| **최종 코드 (S6 제외)** | 76 | +0.16 | 같음 |

- **다 쌓인 더미는 언제나 45°입니다(높이 39, 바닥 80).** 대각선으로 한 칸씩만 내려가므로, 미끄러짐 확률은 경사가 아니라 퍼지는 속도를 정합니다. design.md의 "미끄러짐 확률 = 쌓이는 각도" 설명은 틀렸습니다.
- **S1은 낙하 가속을 바꿀 때만 효과가 있습니다.** 수정 전 가속 0.25는 Noita 중력 1.0이라 쉬는 확률이 0입니다. 0.225로 바꾸면 약 4.7%입니다.
- **S6(왼쪽 먼저)은 더미를 왼쪽으로 약 1칸 기울입니다.**
- **시드 15개로 확인했습니다.** 모래를 높이 200에서 부으면 수정 전 중앙값 68칸(65~77)이 최종 77칸(73~83)이 됩니다.

## 채택 / 변경 / 제외
- **그대로 씀:**
  - S1: 떨어지는 중 확률로 쉬기 (Noita 관측)
  - S2: 첫 낙하 틱은 가속 없이 한 칸 (Noita 관측)
  - S3: 흩어지다 막히면 끝 (Noita 관측)
  - S4: 막혀도 속도와 떨어지는 중 상태 유지 (Noita 관측)
  - 쉬는 상태: 대각선에도 못 가고 양옆이 막히면 쉼 (Noita 관측)
  - S5: 미끄러짐 확률 50, S8: 낙하 가속 0.225 (Noita 관측)
- **바꿔서 씀:**
  - 쉬는 확률은 따로 재질 값으로 두지 않습니다. Noita처럼 낙하 가속에서 계산합니다(가속이 0.25 이상이면 0). (Noita 관측 규칙을 우리 단위로 변환)
  - 상태는 Noita의 state 숫자 대신 `Falling` 표시 하나로 둡니다. 셀의 남는 패딩 바이트를 써서 크기는 12바이트 그대로입니다. (자체 설계)
  - 쉬기·대각선 난수는 실제로 움직일 수 있을 때만 뽑습니다. Noita는 먼저 뽑지만 결과 분포는 같습니다. 휴면을 위한 변경입니다. (자체 설계)
- **쓰지 않음:**
  - S6 왼쪽 먼저: 무작위 순서를 유지합니다. 맞추면 더미가 왼쪽으로 기웁니다(위 측정). (자체 설계, 개발자 확인 필요)
  - 이동 통계: 소비자가 확인되지 않았습니다.
