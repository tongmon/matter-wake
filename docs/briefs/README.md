# 참고 요약

시뮬레이션 메커니즘마다 Noita 분석 자료를 어떻게 참고했는지 남기는 문서입니다. `noita-reference` skill이 [양식](../../.claude/skills/noita-reference/references/brief-template.md)대로 씁니다.

- 파일 이름은 메커니즘 이름입니다. 예: `liquid-flow.md`, `sleep.md`
- 같은 메커니즘을 다시 고칠 때는 새 파일을 만들지 않고 기존 요약을 고칩니다.
- 분석 자료의 문장이나 의사코드를 옮기지 않습니다. 자기 말로 요약하고 절 번호와 줄로 근거를 답니다.
